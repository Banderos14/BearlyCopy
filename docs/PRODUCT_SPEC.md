# Product specification

## Vision
BearlyCopy is a local macOS developer utility that bridges AI coding
agents and AI chats. It captures every final answer from Claude Code
automatically, keeps it with its project and session, and puts it on the
clipboard in one click, ready to paste into ChatGPT for planning and
independent review.

Main flow: **Claude Code → BearlyCopy → ChatGPT Plus** (manual paste).

## Target users
- Developers who plan and review in ChatGPT and implement with Claude Code
  (CLI or Claude Desktop local Code sessions).
- People who run several Claude Code sessions or projects in parallel and
  lose track of which answer belongs where.
- Privacy-conscious users who will not route code through extra cloud
  services or API keys.

## Problem
Long Claude Code answers are tedious to select in a terminal or in the Desktop
app. Selection loses Markdown and code fences, and gets mixed up across
sessions. Pasting a result into ChatGPT "for review" also tends to turn
Claude's claims ("tests pass") into apparent facts.

## User stories
| ID | Story | Phase |
|---|---|---|
| US-1 | As a developer, I can copy Claude's complete last answer with one command or click, without selecting text. | 1 (CLI) / 2+ (UI) |
| US-2 | I can choose the project and session whose result I copy, so parallel work never gets mixed up. | 1 |
| US-3 | I can copy a structured context (request, response, git state, verification status) for an independent ChatGPT review. | 1 |
| US-4 | I only capture projects I explicitly enable. | 1 |
| US-5 | I am warned before exporting text that looks like a secret, and I can preview the export first. | 1 |
| US-6 | I can see that a turn ended with an API error or with background work still running, instead of a misleading "done". | 1 |
| US-7 | I can delete my history. | 1 |
| US-8 | I see a compact Claude status in the notch / menu bar and open history by hovering. | 2+ |
| US-9 | I install and uninstall the integration safely, and my other hooks and settings stay untouched. | 3 |

## MVP scope (Phases 1–3)
- Hook capture of UserPromptSubmit, Stop and StopFailure.
- A local store; session and turn model; Copy Response; Copy Context.
- A CLI now; a menu-bar/notch UI with preview, history and settings later.
- Safe, reversible installation (plugin preferred).

## Non-goals
- Automatic sending to ChatGPT or any chat service; browser automation.
- Any AI API usage (OpenAI or extra Anthropic calls); summarizing or rewriting
  answers.
- Cloud sync, accounts, telemetry, a backend server.
- Capturing Claude Code **cloud** sessions (they do not run local hooks).
- Reading the user's project files, `.env` files or keys.
- Windows or Linux GUI (the Core is portable; the product targets macOS).

## Future scope (post-MVP, not committed)
- Manual import from the clipboard for the ChatGPT → Claude direction.
- Independent verification sources (for example a local test-result file or
  CI status read on demand), shown as *Confirmed locally* only when real.
- SQLite storage, search, retention policy, encryption at rest.
- Support for other agents (Codex CLI, Gemini CLI) through adapters, if they
  offer equivalent hooks.

## Success criteria for the MVP
- No answer is lost or altered: byte-exact copy, verified by tests and on a
  real Mac.
- No result is ever attributed to the wrong session.
- Never blocks or changes Claude Code behavior.
- Zero network traffic generated by BearlyCopy.
