# Phase 5.11 — проверки, которые может сделать только владелец

Всё ниже автоматически проверить нельзя: нужен ваш экран, ваши глаза или
чужое приложение (ChatGPT). Prompt Relay не видит, дошли ли файлы.

## 0. Подготовка
1. В Xcode пересоберите и запустите схему **Prompt Relay** (Debug). В
   Debug-сборке, запущенной в 16:02, нет исправлений 5.11.
2. Закройте второй экземпляр (`~/Applications/Prompt Relay.app`), чтобы в
   чёлке был один остров.
3. Тестовый проект с реальным ходом уже есть: `~/prompt-relay-validation/e2e-511`.
   Остров → «Project and Session» → `e2e-511`.

## 1. Консоль Xcode (предупреждения)
Во время шагов 2–4 следите за консолью Xcode. Не должно быть:
- `Bound preference … tried to update multiple times per frame`
- `It's not legal to call -layoutSubtreeIfNeeded on a view which is already being laid out`
- `Invalid frame dimension (negative or non-finite)`

Если что-то появится, пришлите строку и действие, после которого она
появилась.

## 2. Остров
- Quick Peek: строки не обрезаны, чипы `1× exit ≠ 0` и `1× exit 0` видны.
- Details: прокрутка ответа колёсиком внутри карточки, Back и Esc
  возвращают назад.
- Переключение сессий: выбранная сессия остаётся выбранной после
  перезапуска приложения.
- Вложения: 📎 → выбрать файл → появилась миниатюра → «…» → удалить.
- Relay: глаза и голова следят за курсором, возвращаются в покой, дыхание,
  моргание, радость после Copy. Включите «Уменьшение движения» в
  системных настройках: Relay должен перестать двигаться.

## 3. Вставка в ChatGPT (матрица V8)
Для каждого: ChatGPT Desktop, Safari (chatgpt.com), Chrome (chatgpt.com).
1. В `e2e-511` нажмите «Add all» в Attachments, затем **Copy for ChatGPT**.
2. В ChatGPT вставьте (⌘V) — проверьте, что текст пришёл целиком и в нём
   есть `exit 4`, `calc.py`, `REPORT.md`, `blue.png`.
3. Вернитесь в остров → **Copy 3 Files** → в ChatGPT ⌘V. Запишите, сколько
   файлов прикрепилось.
4. Если не все: попробуйте **Drag All** (перетащить в поле ввода) и
   **Show in Finder** (перетащить из Finder).

Запишите результат по каждой паре «приложение × способ».

## 4. История изображений из буфера (V6)
Settings → Clipboard images → включить. Сделайте снимок экрана в буфер
(⌃⇧⌘4). Спросила ли macOS разрешение на доступ к буферу? Появилось ли
изображение в списке? Затем выключите режим.

## 5. CPU в Release
Соберите схему **Prompt Relay** в Release, запустите, откройте «Мониторинг
системы»: процесс Prompt Relay в покое и при движении мыши.

## Откат плагина (если понадобится)
Реестр плагинов до обновления 0.2.0 → 0.3.0 сохранён в
`~/Library/Application Support/PromptRelay/backups/plugin-registry-before-0.3.0/`
(`installed_plugins.json`, `known_marketplaces.json`, кэш 0.2.0).
Отключить плагин целиком (вместе с захватом ответов): `claude plugin disable
prompt-relay@prompt-relay`. Учтите: marketplace указывает на эту рабочую
копию, поэтому Claude Desktop берёт хуки из текущей ветки `plugin/`.
